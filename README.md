# MeshBench's Homebrew tap

Generated by `.github/workflows/publish-tap.yml` in
[MeshBench/meshbench](https://github.com/MeshBench/meshbench). An edit
made here is overwritten by the next release.

```
brew tap MeshBench/meshbench
brew install --cask meshbench
```

`meshbench` is the application on its own, about 26 MB. Emulated boards
work once Configuration > Setup fetches the emulators.

`meshbench-bundled` carries QEMU and Renode with it, about 118 MB, and
an emulated board boots on first run.

The plain name is the smaller one because a package manager
re-downloads on every release, for a tool you may never point at an
emulated board. A one-off download is a different question, and
[the download page](https://meshbench.github.io/download/) leads with
the bundled build there.
